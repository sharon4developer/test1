# CareerBot IT

OpenClaw agent workspace for Sharon's IT job search.

This is a second, independent agent alongside `career-agent/` (CareerBot, Saskatchewan-first retail-management and direct-support/community-services job search). CareerBot IT has its own workspace, agent id (`careerit`), Telegram bot, application tracker, daily apply cap, and resume identity — the two tracks do not share state.

- Search genuine HR/company-posted IT jobs in Canada (no province restriction) that support PR or a work permit
- Auto-apply only at 75%+ profile fit
- Write a new resume and cover letter for each job
- Read reply email
- Recruiter conversation sends still need confirmation
