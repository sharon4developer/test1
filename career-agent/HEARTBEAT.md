# HEARTBEAT.md

On each heartbeat:

1. Read USER.md, resume/BASE.md, and applications/tracker.md
2. If profile/resume facts or application email are still empty, do not apply. Tell Sharon what is missing.
3. Search only for genuine HR/company-posted IT jobs in Canada that support a work permit / LMIA / visa
4. Skip aggregator spam, staffing blasts, "no sponsorship", PR/citizen-only, and unclear sources
5. Score each job. Skip below 75%
6. For each apply: write a new resume and cover letter under resume/out and cover-letters/out
7. Auto-apply up to 10 today
8. Check readable job/recruiter email for replies
9. Draft conversation replies. Do not send those replies.
10. Update applications/tracker.md
11. Send Sharon a digest

Digest format:

- Searched: Canada IT, HR/company-direct, permit-support
- New jobs scored: N
- Applied (>=75%): N
- Skipped: N (top reasons)
- Replies needing Sharon to send: N
- Applied jobs as bullets: company, title, fit%, resume file
